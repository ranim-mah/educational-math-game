# Tir à la Corde Maths

Un jeu éducatif interactif qui transforme les maths en compétition amusante !

[![Voir la démo](https://img.shields.io/badge/📹-Voir%20la%20démo-red)](Enregistrement%202026-02-13%20231906.mp4)

---

## Description

Deux équipes (ou un joueur vs IA) s'affrontent en résolvant des problèmes mathématiques. Chaque bonne réponse tire la corde vers son camp !

**Développé en JavaScript vanilla pour approfondir mes compétences en développement web.**

---

## Fonctionnalités

- **3 modes** : Duo (2 joueurs) | Solo (vs IA) | Classe (20 questions)
- **4 opérations** : Addition, Soustraction, Multiplication, Division + Mix
- **3 niveaux** : Facile, Moyen, Difficile
- **Extras** : Combos, statistiques, support clavier, timer configurable (30s-3min)

---

## Technologies

- HTML5 + CSS3 (Tailwind)
- JavaScript Vanilla (ES6+)
- Web Audio API (sons)
- LocalStorage (scores)
